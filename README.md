## 🆕 قالب AI Hub الأصلي (v0.1.0)
مبني من الصفر — لا يحتوي أي سطر من أي قالب آخر:

- 🧈 خلفية ورق الزبدة + 🪟 هيدر زجاجي لاصق + 🌙 وضع ليلي بزر وحفظ للاختيار (بلا وميض)
- 📐 نظام قياسات هندسي (شبكة 4px) ومناطق لمس 42px (و44 على اللمس)
- 🧭 **فهرس محتويات تلقائي** لكل مقال + 🧩 **أسئلة منسدلة تلقائية** + بطاقة «الإجابة السريعة»
- 🖼️ تحسين تلقائي للصور (lazy + alt + أولوية للصورة الأولى) + ⏱️ وقت قراءة تلقائي
- 🔗 مشاركة (واتساب/X/فيسبوك/نسخ الرابط) + 📊 جداول منسّقة + 📚 قسم مصادر + بطاقة ختامية
- 🔍 سيو: Open Graph + Twitter Card + سكيما WebSite/SearchAction + BlogPosting + BreadcrumbList
- 🎨 لوحة «مصمّم القالب»: تتحكم في اللون الرئيسي والخلفيات والعرض من واجهة بلوجر بلا كود
- ⚡ بلا أي مورد خارجي (لا خطوط ولا مكتبات) — نظام خطوط المستخدم + SVG مدمج

## 📲 تركيب القالب الجديد (على مدونة تجريبية أولًا!)
1. أنشئ مدونة تجريبية جديدة من blogger.com (مجانية، دقيقتان)
2. من Chrome على الهاتف: فعّل **موقع الكمبيوتر (Desktop site)**
3. **المظهر** ← السهم ⚙️ ← **استعادة (Restore)** ← ارفع `AIHub-theme-v0.1.0.xml` ← **حفظ**
4. راجع: الهيدر، الوضع الليلي، القائمة على الهاتف، مقالًا كاملًا (الفهرس والأسئلة), التخطيط
