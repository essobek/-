# قالب AI Hub — SEO Plus (Free) + تصميم AI Hub (v2)

**المدونة:** https://ai-hub-blog.blogspot.com

## 📁 الملفات
| الملف | الوصف |
|---|---|
| ⭐ **`seoplus-EN-AIHub.xml`** | القالب المعدّل — **v2** (خلفية ورق الزبدة + هيدر زجاجي + وضع ليلي + تصميم المقالات). هذا هو الذي تركّبه |
| `seoplus-EN-original.xml` | النسخة الأصلية قبل أي تعديل (رجوع احتياطي) |
| `seoplus-AR-original.xml` | النسخة العربية كما هي (لم تُعدّل) |

## 🆕 جديد النسخة v2
- 🧈 **خلفية ورق الزبدة** لكل الموقع بنسيج ورقي خفيف (مدمج داخل القالب — صفر طلبات شبكة، صفر تأثير على السرعة).
- 🪟 **هيدر زجاجي عصري**: شفافية + blur + حد سفلي رقيق + ظل ناعم عند التمرير (مع بديل صلب للمتصفحات القديمة).
- 🌙 **زر الوضع الليلي** في الهيدر: يحفظ اختيار الزائر، ويتبع إعداد النظام تلقائيًا، وبلا وميض عند التحميل (يُضبط قبل الرسم).
- 🦶 **فوتر منسّق** + تصحيح نص الحقوق إلى `All rights reserved © Ai Hub`.
- ⚡ **الأداء**: ~13.6KB إضافية فقط (CSS+JS)، بلا صور أو خطوط خارجية، مع احترام `prefers-reduced-motion` وضبط خاص للهاتف.

## 📲 التركيب من الهاتف (دقيقتان)
1. افتح `seoplus-EN-AIHub.xml` ← قائمة **⋮** ← **Download**
2. في Chrome فعّل **موقع الكمبيوتر (Desktop site)**
3. بلوجر ← **المظهر** ← ⚙️ ← **استعادة (Restore)** ← ارفع الملف ← **حفظ**

## 🔙 الرجوع
بنفس الخطوات مع `seoplus-EN-original.xml`.
