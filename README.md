# قالب AI Hub — SEO Plus (Free) + تصميم AI Hub مدمج

**المدونة:** https://ai-hub-blog.blogspot.com

## 📁 الملفات
| الملف | الوصف |
|---|---|
| ⭐ **`seoplus-EN-AIHub.xml`** | القالب المعدّل — SEO Plus Free (إنجليزي) + تصميم AI Hub مدمج. **هذا هو الذي تركّبه** |
| `seoplus-EN-original.xml` | النسخة الأصلية قبل التعديل (للرجوع الاحتياطي) |
| `seoplus-AR-original.xml` | النسخة العربية كما هي (لم تُعدّل) |

## 📲 التركيب من الهاتف (دقيقتان)
1. افتح `seoplus-EN-AIHub.xml` ← من قائمة **⋮** اختر **Download**
2. في Chrome فعّل **موقع الكمبيوتر (Desktop site)**
3. بلوجر ← **المظهر** ← ⚙️ ← **استعادة (Restore)** ← ارفع الملف ← **حفظ**

## 🔙 الرجوع للنسخة الأصلية
نفس الخطوات لكن بملف `seoplus-EN-original.xml` — تعود المدونة كما كانت في 30 ثانية.

## 🎨 ماذا أُضيف للقالب
- **CSS** (داخل b:skin): جداول ملوّنة متجاوبة، ترقيم تلقائي لعناوين H2، بطاقة QUICK ANSWER، أسئلة FAQ قابلة للفتح، تنسيق موحّد للروابط والصور والاقتباسات.
- **JS** (2KB قبل نهاية القالب): يحوّل أي فقرة تبدأ بـ«Quick answer:» إلى بطاقة، وقسم «Frequently asked questions» إلى قائمة قابلة للفتح — تلقائيًا في كل مقال جديد.
- **لم يُمسّ:** الكود الأصلي، الكود المشفّر، كتل السكيما الخمس الموجودة، وحقوق المصمم (Seoplus).
